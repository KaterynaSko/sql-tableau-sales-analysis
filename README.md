Sales Data Analysis Project (SQL & Tableau)

Project Overview
This project focuses on analyzing sales data to extract meaningful business insights using **SQL** for data aggregation and **Tableau** for interactive data visualization.

Tech Stack & Tools
- **Database:** SQLite (via DBeaver)
- **Visualization:** Tableau Desktop / Tableau Public
- **Language:** SQL

Key SQL Queries & Analytics
In this project, I answered the following business questions using SQL:
1. **Monthly Revenue Trends:** Tracked total sales volume for each product category per month.
2. **Top Customers:** Identified the Top 10 high-value customers by total spend.
3. **Product Popularity:** Analyzed total units sold for each product.
4. **Pricing Strategy:** Calculated the average selling price across different product categories.
5. **Sales Peak Times:** Discovered the most popular days of the week for sales.

Tableau Dashboard & Insights
The interactive dashboard built on top of this data highlights:
- **Trend Line:** Comparing monthly sales for Category 1 vs Category 2 on a single axis.
- **KPI Performance:** Displaying average prices per category using Highlight Cards.
- **Seasonality:** A horizontal bar chart showing sales distribution across weekdays.
